BIENVENUE DANS L’END
Alex et Steve sont arrivés dans le vide noir de l’End : une grande île vert pâle et de petits îlots flottent autour des piliers d’obsidienne.
ALEX — déplacement : Z Q S D ou flèches ; sauts enchaînés : maintenir V ; sélectionner arme/bloc : R ; poser un bloc ou attaquer : A ; parler : E.
STEVE — déplacement : O K L M ; sauts enchaînés : maintenir N ; sélectionner arme/bloc : U ; poser un bloc ou attaquer : I ; parler : P.
En caméras séparées, les touches de côté tournent le personnage par pas réglables ; maintiens-les pour continuer. Glisse dans chaque moitié pour orienter sa caméra.
Avec le briquet, A/I allume le bois et les feuilles. La TNT détonne après 4 secondes et détruit les blocs dans un rayon de 8 blocs.
Choisis un bloc dans l’inventaire en bas, puis tourne le personnage vers l’endroit où tu veux le poser.
Glisser la souris pour pivoter/incliner la caméra ; pincer le trackpad pour zoomer.
En écran partagé, glisse la souris dans une moitié pour orienter sa caméra.
